# Decision log

| Date | Decision | Reason |
|---|---|---|
| 2026-11-08 | Keep the working name **OpenNaksha** and package id `in.opennaksha.app` for now. | PLAN.md §12 Q1 is still open. The name is easy to change before the first release. |
| 2026-11-08 | Use a **single `app` module** with feature packages (`core.*`, `feature.*`) instead of multiple Gradle modules. | PLAN.md §8 allows it. Fewer build files and faster builds for a one-person project. We can split into modules later if build times grow. |
| 2026-11-08 | Pin **AGP 8.13.2 / Gradle 8.14.3 / Kotlin 2.2.21 / KSP 2.2.21-2.0.5 / Hilt 2.57.2**, compileSdk/targetSdk 36. | This is a known-compatible set. AGP 9.x changes how Kotlin is configured. Upgrade later with Android Studio's AGP Upgrade Assistant, once the app builds. |
| 2026-11-08 | Use **MapLibre Android 12.3.1** (latest 12.x) and no 13.x / globe builds yet. | It is a stable line with the `ImageSource` + `LatLngQuad` API we need for overlays. It needs no API key. |
| 2026-11-08 | Use **OpenFreeMap "liberty"** (`https://tiles.openfreemap.org/styles/liberty`) as the default basemap style. | It is free, needs no key, and is based on OpenStreetMap (PLAN.md §8). It is kept in one constant, `MapConfig.STYLE_URL`. |
| 2026-11-08 | Use **hatchling** as the pipeline build backend, with the package at `pipeline/opennaksha/`. | It is simple and standard with uv, and gives the `python -m opennaksha.run` layout from PLAN.md §6. |
| 2026-11-08 | applicationId stays `in.opennaksha.app`, but the Kotlin package / Gradle `namespace` is **`app.opennaksha`**. | `in` is a reserved word in Kotlin, so `package in.opennaksha.app` would need backticks in every file. The applicationId (what Android and installs see) is unchanged. |
| 2026-11-08 | Ship an **empty bundled catalog** (`assets/catalog/index.json`, no cities, `generated_at` 1970) until Milestone 2 produces real data. | The app needs something to load on first launch. An empty list is not invented data (PLAN.md §2). |
| 2026-11-08 | Launcher icon is a plain vector map pin (adaptive icon only, minSdk 26). | It is a placeholder until the app name is final. |
| 2026-11-08 | **Scheme id = `{city}-{authority}-{type}-{no}-{area}`** (e.g. `surat-smc-tp-1-laldarwaja`), not `{city}-{type}-{no}` as in PLAN.md §5. | Milestone 1 found collisions. SMC has three different "TP 1" schemes, AMC has fifteen "1"s, AUDA has six, and SMC and SUDA both have a TP 86. The trade-off: if a site changes an area's spelling, that scheme shows up as new + removed. Nothing had been published yet, so `schema_version` stays 1. |
| 2026-11-08 | Add optional **`status_label`** (the site's own wording). "Submitted to Govt." and "Draft – pending with TPO" map to `status: draft`. | The plan's status enum has no value for these stages. The app shows the label next to the status. |
| 2026-11-08 | Add optional `files[].last_hashed`, `overlay.points_sha256`, `index.latest_app_version/url`, and publish `catalog/status.json` (source health). | `last_hashed` drives the 30-day re-hash rule. `points_sha256` makes an edited `.points` file trigger a rebuild. `status.json` lets "failing 3 runs in a row" work across runs. |
| 2026-11-08 | **File change detection:** compare ETag + Last-Modified + Content-Length together. Content-Length alone is weak, so re-hash after 30 days like files that send no headers. | SMC's IIS ETags come from timestamps only. RMC and AMC `/ViewFile` send only Content-Length. TPVD refuses HEAD. |
| 2026-11-08 | **Commit decision comes from the run report**, not from `git diff`. The workflow commits only when there are new/changed/removed schemes, new overlays or changed source health. | `last_checked` changes every run. Committing it weekly would create noise and make every run look like a change. |
| 2026-11-08 | SMC per-scheme "Notifications" pages are **not crawled** for now. | Crawling them adds about 143 page requests plus roughly 10 PDFs each per run. Map and forms come from the listing. Can be added later, gently. |
| 2026-11-08 | **Georeferencing uses an affine fit, not a GDAL warp.** pypdfium2 (Apache/BSD) renders the PDF instead of PyMuPDF (AGPL). | MapLibre's `ImageSource` on 4 corners reproduces an affine transform exactly, so no resampling is needed and no heavy GDAL dependency. TP maps are close to affine. pypdfium2's license fits an MIT repo. |
| 2026-11-08 | Scrapers run in **parallel threads, one per source**. The per-host throttle is still 1 req/s. | The sources are on different hosts. A full run is then as slow as the slowest source, not the sum of all of them. |
| 2026-11-08 | TPVD (townplanning.gujarat.gov.in), RMC and VMC are **not scraped** in the first version (verdict "partial"; see sources.md). VUDA *is* scraped: schemes are grouped from folder names. | TPVD has notifications only, no maps. RMC links use encrypted tokens that may change (they would show up as fake "new files" every week). VMC lists files without a scheme table. The VUDA risk: a renamed folder shows up as removed + new. |
